# More Down Release

Download media URLs and import the result directly into Adobe Premiere Pro.

## Download More Down v0.1.6

[Download the Windows installer](https://github.com/Clapper327/More-Down-Release/releases/download/v0.1.6/More-Down-Setup-0.1.6.exe)

## Installation

1. Download and run the Windows one-click installer.
2. Follow the installer prompts.
3. Open Premiere Pro and choose **Window > UXP Plugins > More Down** if the panel is not already visible.

The installer includes the Premiere Pro panel, local helper, and required media tools. No separate Node.js or helper installation is required.
